# Wichtel

A small Secret Santa draw for a friend group. Static site, no accounts, no server.

The organizer adds names, sets a date and budget, and draws. Each person gets their own link that shows only their own match. Couples can be marked so they never draw each other, and the draw prefers a single gift circle so no two people draw each other. Reroll creates a new draw with a new Draw ID.

Run locally with any static server, for example `python -m http.server`.
